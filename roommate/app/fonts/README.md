# Unitern typography

The Wispr Flow reference uses EB Garamond for editorial headings (including
italics) and Figtree for interface text. These are the same font families,
self-hosted through `next/font/local`; visitors make no font requests to Google.

- Figtree variable 300–900: Google Fonts' `ofl/figtree/Figtree[wght].ttf`.
- EB Garamond variable normal/italic 400–800: the Latin WOFF2 subsets provided by
  the official Google Fonts CSS API on 2026-10-11.

Sources: https://github.com/google/fonts/tree/main/ofl/figtree and
https://github.com/google/fonts/tree/main/ofl/ebgaramond.
Both families are licensed under SIL OFL 1.1; the original licenses are retained
in this directory. The three font files total about 151 KB.
